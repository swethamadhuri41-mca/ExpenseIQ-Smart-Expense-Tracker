# ExpenseIQ – Smart Expense Tracker

## Overview

ExpenseIQ is a Python-based expense management system that helps users track daily expenses, monitor budgets, analyze spending patterns, and receive savings suggestions.

## Features

* Add expenses
* Categorize expenses
* Budget management
* Expense analytics
* Highest and lowest expense tracking
* Savings recommendations
* File storage support

## Technologies Used

* Python
* File Handling
* Lists
* Dictionaries
* Loops
* Conditional Statements

## How to Run

1. Install Python.
2. Download the project.
3. Open terminal.
4. Run:

python expense_tracker.py
